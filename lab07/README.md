# Итоговый проект. База данных маркетплейса

## 1. Общее описание
Данный проект представляет собой комплексную базу данных для маркетплейса, объединяющую все технологии, изученные в течение курса. Проект развивает базу данных, созданную в предыдущих работах, и доводит её до состояния законченного решения с документацией.

## 3. Реализованные компоненты
В файле `final_script.sql` собран единый воспроизводимый скрипт, который создает базу данных «с нуля» и включает в себя:
1. **Схему в 3НФ** со всеми ограничениями целостности (Primary Keys, Foreign Keys, Check, Unique).
2. **Тестовые данные** для содержательной аналитики.
3. **Аналитические представления** (`VIEW`) для типовых отчетов.
4. **Серверную логику**: триггер для аудита цен и функцию для оформления заказа с проверкой остатков (транзакционная целостность).
5. **Современные возможности**: столбец `JSONB` для хранения характеристик товаров и GIN-индекс для его быстрого поиска.
6. **Оптимизацию**: B-tree индекс по цене для ускорения выборки.

## 4. Обоснование проектных решений
- **Выбор ключей:** Использованы суррогатные ключи (`BIGINT GENERATED ALWAYS AS IDENTITY`) для стабильности и независимости от бизнес-правил.
- **Нормализация:** Схема приведена к 3НФ. Данные о продавцах вынесены в отдельную таблицу для устранения транзитивных зависимостей (аномалий обновления).
- **Связь M:N:** Реализована через ассоциативные таблицы `order_items` и `cart_items`.
- **JSONB:** Используется для слабоструктурированных атрибутов товаров, чтобы не создавать десятки пустых колонок (цвет для телефона, автор для книги).
- **Бизнес-логика в БД:** Функции и триггеры гарантируют соблюдение правил безопасности (например, запрет покупки товара при нулевом остатке) на уровне самого хранилища.

## 5. Как развернуть проект
Для полного воссоздания базы данных достаточно открыть файл `final_script.sql` в pgAdmin (Query Tool) и выполнить его целиком. Скрипт написан по принципу «идемпотентности» (сначала удаляет старые таблицы, затем создает новые), поэтому его можно запускать повторно без ошибок.
